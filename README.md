# HerConnect

HerConnect is an AI-powered women collaboration platform that connects women entrepreneurs with skilled women for suitable work opportunities.

## Features

- User Registration and Login
- Entrepreneur and Worker Profiles
- Job Posting and Browsing
- Job Applications
- AI-based Recommendations
- Rule-based Filtering
- SBERT Semantic Matching
- Cross-Encoder Re-ranking
- Ratings and Reviews
- Admin Verification

## Modules

### 1. Worker Module
- Manage worker profile
- Add skills and experience
- Browse recommended jobs
- Apply for jobs
- Track applications

### 2. Entrepreneur Module
- Manage business profile
- Post and manage jobs
- View applicants
- Accept or reject applications
- Get recommended workers

### 3. AI Recommendation Module
- Rule-based filtering
- SBERT semantic matching
- Cross-Encoder re-ranking
- Final ranking of suitable matches
